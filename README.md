# Атлас-путеводитель 2.0

Интерактивный атлас мира: 177 стран с буклетами (обзор, советы туристу, политика, культура, отношения, стереотипы),
природа и чудеса света на карте, машина времени с −3000 до 2024 года, поиск, викторина, сравнение стран.
Перенесён со старой однофайловой версии (`legacy/atlas-v1.html`) на TypeScript + React + MapLibre.

## Как запустить

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev            # запуск для разработки: http://localhost:5173
```

Если во время работы сервера появились новые файлы в `public/img` (например, после `npm run fetch:food`),
сервер разработки нужно перезапустить: за этой папкой он не следит (на Windows слежка за тысячами фото падает).

## Две сборки

```bash
npm run build          # веб-версия в папке dist/ (≈247 МБ; лимит хостинга 256 МБ, файлы до 16 МБ)
npm run build:offline  # версия без интернета: один файл dist-offline/atlas.html (≈178 МБ)
```

**Веб-версия** выкладывается на хостинг целиком (папка `dist/`), пути относительные — работает из любой папки.
**Версия без интернета** открывается двойным щелчком с диска, сервер не нужен. Внутри всё: карта, история, фото 480 и 1200 px.
Файл большой — открывается 2–4 секунды и занимает около 400 МБ памяти, поэтому это вариант для компьютера, не для телефона.

## Проверки

```bash
npm test               # модульные тесты (Vitest)
npm run test:e2e       # сценарии в настоящем браузере (Playwright), компьютер и телефон
npm run lint           # проверка кода (ESLint)
npm run typecheck      # проверка типов (TypeScript)
```

Для `test:e2e` нужен браузер. Один раз: `npx playwright install chromium`. Или взять уже установленный:
`PW_CHANNEL=msedge npm run test:e2e` (Edge есть в каждой Windows). Замер скорости машины времени — только с видеокартой:
`PW_GPU=1 PW_CHANNEL=msedge npm run test:e2e` (откроется окно браузера).

## Подготовка данных

```bash
npm run data           # всё заново: извлечь из legacy/atlas-v1.html, скачать шрифты карты, собрать карту и историю
npm run extract        # тексты и места: из старого HTML + content/enrich/ (новые тексты — править только там)
npm run fetch:commons  # фото мест с Wikimedia Commons (см. reports/stage-6-photos.md)
npm run fetch:food     # фото блюд для раздела «Кухня» (сетка на проверку — reports/food-photos.html)
npm run build:images   # WebP из скачанных фото
```

## Где что лежит

| Папка | Что там |
|---|---|
| `legacy/` | старая версия атласа — исходник для извлечения |
| `content/` | тексты: страны (`countries/KAZ.json`), новые тексты (`enrich/`), места, история, эпохи, источники фото |
| `public/` | картинки и карты: фото, значки, границы, рельеф, история по векам |
| `scripts/` | скрипты подготовки данных и сборки без интернета |
| `src/app/` | приложение, раскладка экрана, роутер на `location.hash` |
| `src/map/` | карта MapLibre: стиль, слои, нажатия, клавиши; `time/` — машина времени |
| `src/booklet/` | буклет страны и 6 вкладок, исторические буклеты, панель эпохи |
| `src/search/` | поиск: нечёткое сравнение, список того, что ищем, поле с подсказками |
| `src/quiz/`, `src/tour/`, `src/compare/` | викторина, случайная экскурсия, сравнение стран |
| `src/lib/asset.ts` | все обращения к файлам сайта (в версии без интернета — из встроенных данных) |
| `src/store/` | общее хранилище состояния (Zustand) |
| `src/styles/` | цвета и шрифты (`tokens.css`), темы |
| `src/content/schema.ts` | схемы данных (Zod) |
| `tests/unit/`, `tests/e2e/` | модульные тесты и сценарии в браузере |
| `reports/` | отчёты по этапам и скриншоты |
| `docs/` | задание (`PROMPT.md`) и записка для продолжения работы (`HANDOFF.md`) |

## Как вернуть предыдущую версию

Каждая версия отмечена в git меткой (`v2.0.0`, `v2.1.0`), готовые сборки прошлых версий — в `release/backup-*`.

```bash
git checkout v2.0.0      # посмотреть старую версию (вернуться к новой: git checkout main)
git revert --no-edit v2.0.0..main   # насовсем отменить всё, что сделано после v2.0.0 (история сохранится)
```

Или без git: распаковать `release/backup-2.0.0/atlas-2.0.0-web.zip` (веб-версия) или открыть `atlas.html`
из `atlas-2.0.0-offline.zip`.
