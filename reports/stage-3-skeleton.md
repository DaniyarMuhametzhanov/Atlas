# Этап 3 — каркас

- Vite 5 + React 18 + TypeScript (strict), ESLint 9 + Prettier, Vitest.
- Раскладка: компьютер (≥1000 px) — карта 62% слева и буклет справа, каждый прокручивается отдельно;
  планшет (700–999 px) — карта сверху, буклет снизу; телефон (<700 px) — карта на весь экран и выдвижная панель
  снизу с тремя положениями (нажатие или перетаскивание ручки, стрелки ↑↓ с клавиатуры).
- Темы: «как в системе» / светлая / тёмная, выбор запоминается. Цвета — CSS-переменные в `src/styles/tokens.css`.
- Роутер на `location.hash`: `#/`, `#/country/KAZ/culture`, `#/sources`. Адрес без вкладки открывает последнюю открытую.
- Хранилище Zustand: маршрут, последняя вкладка, тема, слои карты (запоминаются), положение панели, машина времени.
- Буклет: шапка (обложка, название, девиз, «чем знаменита», штамп со столицей, кнопки «Поделиться» / «Распечатать»;
  «Сравнить» — этап 9) и 6 вкладок на перенесённых данных. Пустые разделы — «Скоро появится».
  Вкладки переключаются мышью, клавишами 1–6, ← → Home End (когда фокус на строке вкладок).
- Карта пока заглушка (снимок рельефа), MapLibre — этап 4.
- Шрифты Unbounded (заголовки) и Golos Text (текст) подключены из npm (@fontsource), работают без интернета.
- Короткий список стран грузится сразу, полный файл страны — при открытии (отдельный файл ~2 КБ).
  Главный JS-файл — 355 КБ (100 КБ в сжатом виде).

Проверено (Playwright, `reports/screens/`): 1300 / 820 / 390 / 360 px, светлая и тёмная тема — ошибок в консоли нет,
горизонтальной прокрутки нет; клавиша 4 → «Культура», → → «Отношения», новая страна открывается на последней вкладке.
