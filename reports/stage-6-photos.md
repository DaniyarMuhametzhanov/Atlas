- Обложка и все фото открытой вкладки — одна галерея; зум колёсиком / двойным нажатием / двумя пальцами,

- **Сайт целиком (`dist`) — 244,8 МБ из 256**, файлов больше 16 МБ нет.

## Почему 1600, а не 2000 px, и без AVIF

1. Wikimedia отдаёт уменьшенные копии только стандартных ширин: 960, 1280, **1920**. Ширину 2000 сервер не принимает (400).
2. Лимит хостинга — 256 МБ на всё. WebP + AVIF в трёх размерах заняли бы **535,8 МБ**. AVIF экономил всего ~15%,
   а хранить два формата — вдвое больше места, поэтому оставлен один WebP.
3. Только WebP с версией 1920 px — всё равно ≈ 330 МБ. Скрипт `build:images` сам подобрал самый качественный вариант,
   который помещается: **1600 px, качество 52**.
4. Если нужна чёткость 1920–2000 px — фото надо хранить отдельно от сайта (например, Cloudflare R2, бесплатно до 10 ГБ).

## Как это было сделано

| Шаг | Где | Кто запускал |
|---|---|---|
| Скачать 560 фото 1920 px | `npm run fetch:commons` | владелец, у себя (из облака Commons отвечал 429 «слишком много запросов» на ~90% запросов) |
| Найти фото для мест без фото | `npm run fetch:commons -- --search` → `reports/commons-candidates.html` | владелец |
| Подключить выбранные | `content/photo-picks.json` → `npm run fetch:commons -- --apply` | Claude + владелец |
| WebP 480 / 1200 / 1600 и проверка лимита | `npm run build:images` | владелец |

## Что не так / на решение владельца

1. **«Полёт Гагарина»** — на фото аппарат «Восток-5» (Быковский), не «Восток-1». Корабли одной серии, но если нужна точность — заменить.
2. **Обложка ЮАР** — камни на вершине Столовой горы, самой горы не видно.
3. **13 старых фото под FAL / GFDL** (свободные, но не из списка промпта). Сверить, нет ли у них второй лицензии CC BY-SA,
   можно у себя: `npm run fetch:commons -- --verify` → `reports/commons-check.md` (из облака API Commons отвечает 429).
4. **Находки эпох** с фото пока не показываются — это панель эпохи, этап 7.
5. Мелочь из этапа 5: «Претория» в штампе «Столица» переносится как «Претори / я».
6. Папка `public/img/legacy` (6,4 МБ, старые 560 / 224 px) больше не используется — её можно убрать, если понадобится место.
