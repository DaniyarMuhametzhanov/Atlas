# Этап 6 — фото на весь экран

## Главная проблема: Wikimedia Commons по-прежнему закрыт

Проверка в начале сессии (28.10.2026):

```
curl https://commons.wikimedia.org/w/api.php  → 000 (прокси ответил 403 — сайт не разрешён)
curl https://upload.wikimedia.org/            → 000 (то же)
```

Поэтому сделан запасной вариант из HANDOFF (п. 5): просмотр на весь экран работает на старых фото,
а скрипты для Commons написаны и проверены «вхолостую» — их нужно просто запустить, когда доступ откроют.

## Что не получилось и почему

1. **Крупных фото нет.** 386 из 560 старых фото есть только миниатюрой 224–240 px, 174 — обложкой 560 px.
   На весь экран они показаны вдвое крупнее своего размера, поэтому мягкие. Исправится одной командой, когда откроют Commons.
2. **Сетку найденных фото показать не могу** — поиск идёт через Commons. Список того, что искать
   (обложки GNQ / ZAF / HND, Балхаш, Столовая гора, Высокий Тауэрн, Пещеры Бату, Малабо, Копан,
   Библия Гутенберга, полёт Гагарина, смартфон), лежит в `content/photo-wanted.json`.
3. **Находки эпох с фото** пока нигде не показываются — панель эпохи делается на этапе 7.
   Она будет использовать тот же компонент `<Photo>`, просмотр подключится сам.
4. **13 старых фото с лицензией не из списка промпта:** 12 — FAL (Free Art License), 1 — GFDL 1.2 (`serengeti`).
   Обе лицензии свободные, но промпт разрешает только CC0 / CC BY / CC BY-SA / PD. Многие такие файлы на Commons
   имеют вторую лицензию CC BY-SA — `fetch:commons` это покажет. Нужно решение владельца: оставить или заменить.
   Фото: kourion-theatre, lala-mustafa-pasha-mosque-famagusta, iguazu-falls, aurora-troms, pamukkale-travertines,
   black-forest-germany, nine-arch-bridge-ella, dallol-hydrothermal, salzburg-old-town-hohensalzburg, charles-bridge,
   ruwanwelisaya, bastei-bridge, serengeti.
5. **Оценка места на хостинге:** 560 фото × 6 файлов (WebP + AVIF в трёх размерах) ≈ 250–400 МБ — может не влезть
   в 256 МБ. `build:images` считает и останавливается с ошибкой; тогда уберём AVIF 2000 или снизим качество.

## Когда Commons откроют — порядок действий

```bash
npm run fetch:commons -- --search   # → reports/commons-candidates.html (сетку — владельцу)
# владелец выбирает → content/photo-picks.json: [{ target, id, title, author, license, url }]
npm run fetch:commons -- --apply    # подключить выбранные и скачать всё (≈ 560 файлов, пауза 1 с — около 20 минут)
npm run build:images                # WebP/AVIF 480/1200/2000 + проверка лимитов
```
