# Передача дел: где остановились

Документ для новой сессии, которая продолжает работу. Полное задание — `docs/PROMPT.md`.
Отчёты по сделанным этапам — `reports/stage-*.md`, скриншоты — `reports/screens/`.

## Как общаться с владельцем проекта

- По-русски, максимально простыми словами. Сложный термин: сначала объяснить простыми словами, потом дать термин в скобках
  жирным: «рисование через видеокарту (**WebGL**)».
- После каждого этапа — короткий отчёт: что сделано, скриншоты, что не получилось и почему. В конце выделить
  «Главное» (2–5 пунктов). Без пафоса.
- Если что-то в задаче невозможно или противоречит другому пункту — сказать прямо и предложить замену.
- Работа сохраняется в `main` этого репозитория после каждого этапа (коммит + push). Владелец забирает её `git pull`
  в папку `C:\Users\rando\Desktop\Atlas` и запускает `npm install` → `npm run dev`.

## Все 10 этапов закончены

Что осталось открытым — `CHANGELOG.md`, раздел «Что не получилось». Кандидаты на следующую работу:
- скорость на телефоне (Lighthouse 57): отложенный запуск карты или облегчённый стиль на старте;
- долгие кадры машины времени при смене века (MapLibre разбирает тысячи многоугольников XIX–XX веков);
- обновление зависимостей до новых основных версий (`npm audit`: Vite, Vitest, MapLibre, sharp, zod);
- фото блюд для оставшихся 301 (`reports/food-photos.html`, раздел «Без фото»).

**Этап 9 коротко.** Поиск — `src/search/` (свой нечёткий поиск, без Fuse.js). Перелёт карты по запросу — `flyTo` в хранилище:
если у него есть `iso`, карта ждёт открытия этой страны. Викторина «Найди на карте» включает `mapPick` в хранилище:
нажатие на карту отвечает на вопрос, подписи стран скрыты. `highlight` — обводка стран вне буклета.
Адреса: `#/compare/KAZ/RUS`, `#/quiz`, `#/tour`.

**Этап 10 коротко.** Все обращения к файлам — `src/lib/asset.ts` (`assetUrl`, `fetchAsset`); в версии без интернета файлы
лежат в `window.__ATLAS_ASSETS`, карта берёт рельеф и шрифты по адресу `embed://`. Не обращаться к `public/` мимо этих функций —
иначе версия без интернета сломается. Фото блюд — `npm run fetch:food` (кэш поиска в `assets-src/food/`, не в git).

**Проверка в браузере на компьютере владельца:** расширение Claude для Chrome может быть не подключено. Автотесты:
`PW_CHANNEL=msedge npm run test:e2e` (Edge есть в Windows); замер скорости — `PW_GPU=1 PW_CHANNEL=msedge npm run test:e2e`.
Порты 5173 и 5174 часто заняты серверами владельца — для своих проверок брать другой (автотесты используют 4173).
Осторожно: `page.evaluate`, который возвращает объект карты (`map.jumpTo(...)`), роняет процесс теста по памяти —
писать `void map.jumpTo(...)`.

**Как устроены тексты.** Новые тексты живут в `content/enrich/<КОД>.json` — это «источник правды». `npm run extract`
собирает `content/countries/<КОД>.json` из старого HTML и накладывает enrich сверху (объекты сливаются по полям,
массивы заменяются целиком; климат пишется коротко: `{ tMin: [12], tMax: [12], rain: [12] }`). Править тексты —
только в enrich, потом `npm run extract`. На Windows extract пересохраняет файлы машины времени с другими концами строк —
перед коммитом верните их: `git checkout -- content/history content/epochs content/places content/legacy-keys.json reports/stage-2-extract.md`.
**`content/sources.json` так возвращать нельзя, если с прошлого коммита добавлялись фото** (`fetch:food`, `fetch:commons -- --apply`) —
пропадут их записи. Сохраните копию до extract и верните её после.

**Правила проверки (как сделано для первых 50):** цифры — из ЦРУ World Factbook, Всемирного банка (население, ВВП),
переписей; индекс свободы — Freedom House 2026; курсы — на дату проверки; визы — сводные таблицы Википедии для граждан
Казахстана и России; климат — нормы 1991–2020 **столицы**; руководители — свежие новости (выборы 2026 года!).
У каждой страны список `sources` (показывается внизу вкладки «Обзор»). Тест `tests/unit/enrich.test.ts` не пропустит
заглушки вроде «уточните» и страны без источников.

На решение владельца из этапа 6: фото «Полёт Гагарина» (там «Восток-5»), обложка ЮАР, 13 фото под FAL / GFDL.

**Wikimedia из облака:** API и upload.wikimedia.org отвечают 429 почти на всё (общий адрес облака). Скачивать фото —
у владельца: `npm run fetch:commons`. Место: сайт 248 МБ из 256.

## Устройство проекта (коротко)

- Данные: `npm run data` = `extract` (из legacy HTML) → `fetch:glyphs` (шрифты подписей карты) → `build:map` → `build:history`
  (Cliopatria и historical-basemaps скачиваются в `assets-src/`, не в git). `npm run build:booklets` — проверка и индекс буклетов.
  `extract` чистит только свои папки (`public/img/legacy`, `public/img/icons`, `public/data/history`).
- `src/content/schema.ts` — схемы Zod; `src/content/index.ts` — список стран сразу, полный файл страны по требованию,
  `getPhoto` / `photoUrl` по `sources.json`.
- `src/map/` — карта (`style.ts` — слои и приоритеты, `AtlasMap.tsx` — нажатия, выбор страны, режимы).
  В автотестах карта доступна как `window.__atlasMap`.
- `src/booklet/` — шапка, вкладки (`tabs/`), графики (`charts/`), запасные рисунки (`art/`), панель эпохи и исторический буклет.
- `src/map/time/` — машина времени: данные по векам, слои (`timeLayers.ts`), проигрыватель (`TimeBar.tsx`).
  Скорость проверять у себя: `?fps` в адресе.
- `src/ui/photos/` — `<Photo>` (srcset, AVIF, ленивая загрузка, данные для подписи) и `useGallery(ref, ready)` —
  все `<Photo>` внутри контейнера становятся одной галереей PhotoSwipe.
- Фото: `scripts/lib/photos.ts` (общее), `fetch-commons.ts`, `build-images.ts`. Оригиналы — `assets-src/commons/` (не в git,
  только у владельца). Выбранный вариант «на весь экран» — `public/img/fullscreen.json`.
- Windows: не класть рядом файлы, различающиеся только регистром (`Art.tsx` / `art.ts`).
- Тестовая страна со всеми разделами: `tests/fixtures/KAZ-full.json` (значения «ТЕСТ»). В режиме разработки подставляется
  через `window.__atlasFixtures = { KAZ: … }` (см. `loadCountry`).

## Проверки перед каждым коммитом

```bash
npx tsc --noEmit && npx eslint . && npx vitest run && npm run build
```
Плюс `npm run test:e2e` (сценарии Playwright из раздела 14: консоль без ошибок, нет горизонтальной прокрутки на
1300 / 390 / 360 px, светлая и тёмная тема, буклет, фото, поиск, булавки, машина времени). Перед выпуском —
`npm run build:offline` и открыть `dist-offline/atlas.html` с диска. Особенность тестового браузера: снимок **всего экрана телефона**
теряет WebGL под закреплённой панелью — карту снимать отдельно с `clip`.
