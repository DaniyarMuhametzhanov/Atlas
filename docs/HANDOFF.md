## Следующий: этап 6 — фото на весь экран

Почему новая сессия: в прошлой сессии внешние сайты были закрыты (`commons.wikimedia.org`, `upload.wikimedia.org` → 403
от прокси). Владелец открыл доступ ко всем доменам в настройках окружения — новая сессия должна это подхватить.
**Первым делом проверить:** `curl -s -o /dev/null -w "%{http_code}" https://commons.wikimedia.org/w/api.php` → ждём 200.

Что сделать (раздел 5 и этап 6 промпта):
1. `scripts/fetch-commons.ts` — по `content/sources.json` (у каждого фото есть `url` страницы файла на Commons) через
   API Commons (`action=query&prop=imageinfo&iiprop=url|size|extmetadata&iiurlwidth=2000`) скачать оригиналы/миниатюры
   2000 px. Проверить автора и лицензию из `extmetadata` (сравнить с тем, что уже записано). Вежливо: User-Agent с контактом,
   паузы между запросами.
2. Для стран без обложки (GNQ, ZAF, HND), мест без фото (Балхаш, Столовая гора, Высокий Тауэрн; Пещеры Бату, Малабо, Копан;
   находки: Библия Гутенберга, полёт Гагарина, смартфон) — найти фото на Commons (только CC0 / CC BY / CC BY-SA / PD;
   без карт, флагов, схем, гербов, гравюр, случайных людей). **Сетку найденных фото показать владельцу на проверку**
   до того, как подключать.
3. `scripts/build-images.ts` (sharp): WebP + AVIF в 480 / 1200 / 2000 px → `public/img/<id>-<w>.webp|avif`;
   обновить `sources.json` (`sizes`, `files`). Следить за лимитом хостинга: файл ≤ 16 МБ, всего ≤ 256 МБ.
4. PhotoSwipe 5: любое фото (обложка, карточки мест, чудеса, находки, блюда) открывается на весь экран; все фото раздела —
   одна галерея; зум, свайп, ← →, Esc, жест вниз; подпись: название, страна, автор, лицензия, ссылка на Commons.
   В буклете `srcset` 480/1200 и `loading="lazy"`, на весь экран — 2000; пока грузится большое — показывается маленькое.
5. Если Commons всё ещё закрыт: сделать п. 4 на старых фото (560 / 224 px) и честно сказать, что крупных фото нет.

## Устройство проекта (коротко)

- Данные: `npm run data` = `extract` (из legacy HTML) → `fetch:glyphs` (шрифты подписей карты) → `build:map`.
  `extract` чистит только свои папки (`public/img/legacy`, `public/img/icons`, `public/data/history`).
- `src/content/schema.ts` — схемы Zod; `src/content/index.ts` — список стран сразу, полный файл страны по требованию,
  `getPhoto` / `photoUrl` по `sources.json`.
- `src/map/` — карта (`style.ts` — слои и приоритеты, `AtlasMap.tsx` — нажатия, выбор страны, режимы).
  В автотестах карта доступна как `window.__atlasMap`.
- `src/booklet/` — шапка, вкладки (`tabs/`), графики (`charts/`), запасные рисунки (`art/`).
- Тестовая страна со всеми разделами: `tests/fixtures/KAZ-full.json` (значения «ТЕСТ»). В режиме разработки подставляется
  через `window.__atlasFixtures = { KAZ: … }` (см. `loadCountry`).
