# Промпт: «Атлас-путеводитель 2.0» — перенос на нормальный стек и большое обновление

> **Как пользоваться:** скопируй всё, что ниже линии, в новый чат и приложи файл `Атлас-путеводитель.html`.
> Задача большая, поэтому исполнитель работает по этапам и после каждого показывает результат.

---

## 0. Роль и главная цель

Ты — опытный фронтенд-разработчик (TypeScript, React, WebGL-карты), картограф и редактор туристических путеводителей.

Тебе дают готовый интерактивный атлас мира. Сейчас это **один HTML-файл около 15 МБ**, в котором вперемешку лежат код, тексты, фото и карты.

**Цель:**
1. Перенести атлас в нормальный проект на современном стеке и ничего при этом не потерять: ни данные, ни тексты, ни фото, ни функции.
2. Разделить буклет страны на **6 вкладок**: Обзор, Туристу, Политика, Культура и народы, Отношения, Стереотипы.
3. Сделать просмотр **любого фото на весь экран**.
4. Исправить слабые места карты: наезжающие подписи, пропадающие значки, детали границ.
5. Улучшить машину времени, поиск, оформление; добавить обучающие режимы.

**Правила общения со мной:**
- Пиши по-русски, простыми словами. Сложный термин сначала объясни, а потом дай его в скобках: «рисование через видеокарту (**WebGL**)».
- После каждого этапа присылай короткий отчёт: что сделано, скриншоты, что не получилось и почему.
- Если что-то в задаче противоречит другому пункту или невозможно, скажи прямо и предложи замену. Не делай вид, что сделал.

## 1. Что уже есть в старом файле (это нужно перенести)

### 1.1. Данные внутри старого HTML (глобальные переменные JavaScript)

| Переменная | Что хранит |
|---|---|
| `C` | Страны (177 шт., ключ — английское имя из world-atlas): `n` — название по-русски, `r` — регион (`eu`, `me`, `as`, `af`, `am`, `oc`), `cap` — столица, `tag` — короткий девиз, `i` — вступление, `h` — вехи истории `[[год, текст]]`, `s` — достопримечательности `[[место, описание]]`, `f` — интересный факт |
| `X` | Для каждой страны: `rel` — отношения с соседями, `men` — характер и ценности, `cus` — 3 обычая |
| `P` | Для каждой страны: `p` — политическое устройство, `t` — технологии и инфраструктура, `d` — `[уровень опасности 1–4, пояснение]`, `m` — настроения граждан |
| `FAME` | Чем знаменита страна (подпись под значком) |
| `MOT`, `ICONFIX` | Тема рисунка-значка страны |
| `ART` | Модуль, который рисует запасные SVG-картинки (если нет фото) |
| `NAT`, `NTYPE` | Природные места `[страна, название, тип, долгота, широта, описание, главное?]` и типы природы |
| `RES` | 57 заповедников (добавляются в `NAT` с типом `reserve`) |
| `WON`, `WKIND` | 21 чудо света `[страна, название, вид a/n/p, долгота, широта, описание, ключ фото]` и названия видов |
| `PH` | Фото: `{a: автор, l: лицензия, u: ссылка на Commons, c: обложка 560×280, t: миниатюра 224×112}` (data URI) |
| `PC`, `PS`, `PN` | Какое фото к чему: обложка страны, достопримечательность (`"Страна\|Место"`), природное место |
| `PI`, `PIN`, `WIC` | Значки 72×72 для стран, природных мест и чудес света |
| `HB`, `HBA` | 77 исторических буклетов (`k` — имена в данных, `n`, `yrs`, `cap`, `i`, `h`, `z`, `ph`) и синонимы имён |
| `CLIO` | Исторические границы: `d` — TopoJSON в gzip+base64, `n` — английские имена (≈1550), `r` — русские имена |
| `CSPAN` | Для каждого исторического государства — годы `[первый, последний]` |
| `HIST`, `HRU` | Годы эпох (48 шт.) для панели эпохи и старый словарь переводов |
| `EV`, `EVLANE` | События мировой истории для панели эпохи |
| `FINDS`, `FPH` | 49 находок и открытий (год, название, описание) и их фото |
| `RELIEF` | Снимок рельефа NASA Blue Marble 3840×2000 (JPEG, data URI) |
| `TOPO` | Границы стран world-atlas `countries-110m` |

### 1.2. Функции, которые должны работать и после переноса
- Карта мира с рельефом и переключателем «Рельеф / Регионы».
- Значки «чем знаменита», булавки природы, заповедников и чудес света; всплывающие подсказки.
- Нажатие на страну или значок открывает буклет и подсвечивает страну.
- Поиск страны и кнопка «Случайная страна».
- Клавиши: WASD и стрелки — двигать, Shift — быстрее, Q/E и −/+ — масштаб, R — весь мир.
- Машина времени:
  - границы по годам с 3000 до н.э. по 2024 год;
  - пуск / пауза, скорость 0.5×–4×, полоса прокрутки лет, поле «перейти к году»;
  - клавиши `[` `]` — эпоха назад / вперёд, пробел — пуск / пауза;
  - колонии окрашены в цвет своей империи;
  - нажатие на государство открывает исторический буклет;
  - панель эпохи: крупнейшие государства, события, находки с фото.
- Тёмная и светлая тема (по настройке системы).

### 1.3. Известные проблемы, которые нужно решить
- При увеличении карты подписи и значки мешают друг другу, и некоторые места не показываются никогда (например, острова Комодо и Чеджу).
- Границы стран грубые (масштаб 110m), мелкие острова теряются.
- Фото маленькие (560×280 и 224×112), их нельзя открыть крупно.
- Буклет — одна длинная лента, информацию трудно найти.
- В древности на карте мало государств: набор Cliopatria показывает только государства, без племён.

## 2. Стек технологий

| Задача | Технология | Почему |
|---|---|---|
| Язык | **TypeScript** (строгий режим, `strict: true`) | Проверка типов ловит ошибки ещё до запуска |
| Сборка и запуск для разработки | **Vite 5** | Быстрый сборщик: изменения видны в браузере сразу |
| Интерфейс | **React 18** | Экран собирается из отдельных частей (**компонентов**): вкладка, панель, кнопка |
| Карта | **MapLibre GL JS 5** | Рисует через видеокарту — плавно даже со множеством объектов. Сама расставляет подписи без наложений по приоритетам и уровням масштаба. Умеет собирать булавки в кружки с числом (**кластеры**). Есть вид «глобус» |
| Общее состояние (выбранная страна, год, вкладка, фильтры) | **Zustand** | Одно маленькое хранилище, которое видят все компоненты |
| Адрес страницы | Свой маленький роутер на `location.hash` | Ссылка `#/country/KAZ/tourist` открывает нужную страну и вкладку |
| Поиск | **Fuse.js** | Нечёткий поиск: прощает опечатки |
| Фото на весь экран | **PhotoSwipe 5** | Увеличение, листание свайпом, закрытие жестом вниз |
| Графики (климат, состав населения) | **Chart.js 4** | Простые и лёгкие графики |
| Проверка данных | **Zod** | Проверяет, что у каждой страны заполнены все обязательные поля, и показывает понятную ошибку, если нет |
| Стили | CSS Modules + CSS-переменные для тем | Стили не конфликтуют между компонентами, темы меняются заменой переменных |
| Подготовка фото | **sharp** (скрипт Node.js) | Делает WebP и AVIF в трёх размерах |
| Подготовка карт | **mapshaper** | Упрощает и сжимает границы |
| Тесты | **Vitest** (логика) + **Playwright** (сценарии в настоящем браузере) | Проверяют, что ничего не сломалось |
| Версия без интернета | **vite-plugin-singlefile** | Собирает весь сайт в один HTML-файл |
| Качество кода | ESLint + Prettier | Единый стиль и поиск типичных ошибок |

Все версии фиксируются в `package-lock.json`. Новую библиотеку добавляй, только если объяснишь, зачем она нужна.

Страны в новом проекте определяй по коду **ISO 3166-1 alpha-3** (KAZ, RUS, FRA), а не по английскому названию. Таблицу соответствия старых ключей кодам сохрани в `content/legacy-keys.json`.

### 2.2. Две сборки
- `npm run dev` — запуск для разработки.
- `npm run build` — **веб-версия**:
  - страница и данные лежат отдельными файлами, тяжёлое подгружается по требованию;
  - каждый файл не больше 16 МБ (это ограничение хостинга), всего не больше 256 МБ.
- `npm run build:offline` — **один HTML-файл**: всё встроено, работает без интернета, размер не ограничен. Фото в этой сборке — размеров 480 и 1200 px.
- `npm test` — все тесты.

## 3. Схема данных страны (`content/countries/KAZ.json`)

Опиши её схемой Zod в `src/content/schema.ts`. Ниже пример. Поля со знаком `?` можно не заполнять, тогда вкладка покажет пометку «Скоро появится».

```ts
type Country = {
  id: string;                 // "KAZ"
  name: string;               // "Казахстан"
  nameEn: string;             // "Kazakhstan"
  region: "eu"|"me"|"as"|"af"|"am"|"oc";
  capital: string;
  tagline: string;            // короткий девиз
  fame: string;               // чем знаменита
  updated: string;            // "2026-10" — когда проверены данные

  overview: {
    intro: string;
    facts: { area: number; population: number; gdpPerCapita?: number };
    timeline: { year: string; text: string }[];
    funFact: string;
  };

  tourist: {
    sights: Place[];          // что посмотреть
    nature: string[];         // ссылки на content/places/nature.json
    reserves: string[];
    wonders: string[];
    practical?: {
      currency: string; rateHint?: string;
      languages: string[];
      phrases?: { ru: string; local: string; say: string }[];   // 5 фраз
      plugs: string; voltage: string;
      timezone: string;
      visaKZ?: string; visaRU?: string;   // «проверьте перед поездкой»
      bestSeason: string;
    };
    climate?: { month: number; tMin: number; tMax: number; rainMm: number }[]; // 12 месяцев, столица
    food?: { name: string; text: string; photo?: string }[];                   // 3–5 блюд
    etiquette: { do: string[]; dont: string[] };
    danger: { level: 1|2|3|4; text: string; asOf: string };
  };

  politics: {
    system: string;           // как устроена власть, простыми словами
    leaders?: string;         // кто у власти
    parties?: string;
    mood: string;             // настроения граждан
    economy?: string;
    techInfra: string;
    freedom?: { source: "Freedom House"|"V-Dem"; score: string; year: number }[];
  };

  culture: {
    ethnic?: { group: string; percent: number }[];
    languages?: string[];
    religions?: { name: string; percent?: number }[];
    character: string;        // характер и ценности
    traditions: string[];
    holidays?: { date: string; name: string; text: string }[];
    people?: { name: string; who: string }[];   // 3–5 известных людей
  };

  relations: {
    internal?: string;        // как уживаются народы внутри страны
    neighbors: string;        // соседи
    world?: { country: string; status: "союз"|"дружба"|"нейтрально"|"напряжённость"|"конфликт"; text: string }[];
    attitudes?: { toward: string; text: string; source: string; year: number }[]; // по опросам
  };

  stereotypes?: {
    about: { myth: string; reality: string; source?: string }[];   // о жителях страны
    held:  { myth: string; reality: string; source?: string }[];   // жителей о других
  };

  photos: { cover?: string; gallery?: string[] };   // id фото из sources.json
};

type Place = { name: string; text: string; photos?: string[]; lon?: number; lat?: number };
```

Каждое фото описывается в `content/sources.json`: `{ id, title, author, license, url, sizes: [480, 1200, 2000] }`.

## 4. Буклет с вкладками

### 4.1. Шапка (видна всегда, над вкладками)
- Обложка во всю ширину панели. Нажатие открывает её на весь экран.
- Название, девиз, «чем знаменита», штамп со столицей.
- Кнопки: «Поделиться», «Сравнить», «Распечатать».

### 4.2. Вкладки
- На компьютере вкладки идут строкой под шапкой. На телефоне это строка, которую можно листать вбок, и она прилипает к верху при прокрутке.
- Иконка и подпись: 📖 Обзор · 🧳 Туристу · 🏛 Политика · 🎭 Культура и народы · 🤝 Отношения · 💭 Стереотипы.
- Последняя открытая вкладка запоминается. Адрес меняется: `#/country/KAZ/culture`.
- Переключаться можно клавишами 1–6 и стрелками, когда фокус на строке вкладок.
- Пустой раздел не прячется: показывается пометка «Скоро появится», чтобы было видно, чего не хватает.

### 4.3. Содержание вкладок

**📖 Обзор**
- Вступление (3–5 предложений).
- Карточки с цифрами: площадь, население, ВВП на человека, столица.
- Вехи истории — вертикальная линия времени.
- «Знаете ли вы?» и «Соседи по карте» (кнопки перехода).

**🧳 Туристу**
- Что посмотреть: карточки с фото. У главных мест — галерея из 3–5 фото.
- ★ Чудеса света, заповедники, природа — карточки с пометкой вида.
- Практическая информация — таблица: валюта и примерный курс, языки, 5 полезных фраз (по-русски / по-местному / как произносить), розетки и напряжение, часовой пояс, виза для граждан Казахстана и России, лучший сезон.
- Климат: график по 12 месяцам (линии — минимальная и максимальная температура, столбики — осадки).
- Кухня: 3–5 блюд с фото.
- Этикет: два списка — «Можно» ✅ и «Лучше не надо» ❌.
- Уровень опасности: шкала 1–4, пояснение, дата оценки и совет проверить рекомендации МИД.

**🏛 Политика**
- Как устроена власть — простыми словами, с объяснением терминов. Например: «парламентская республика (главный — премьер-министр, которого выбирает парламент)».
- Кто у власти, главные партии.
- Настроения граждан.
- Экономика, технологии и инфраструктура.
- Оценки свободы — Freedom House или V-Dem, с годом. Это внешняя оценка, а не мнение атласа.

**🎭 Культура и народы**
- Этнический состав — круговая диаграмма и список с процентами, с источником (перепись и её год).
- Языки и религии.
- Характер и ценности.
- Традиции, главные праздники (дата и смысл).
- Известные люди: 3–5 человек.

**🤝 Отношения**
- **Внутри страны:** как живут вместе разные народы, были ли конфликты, как сейчас.
- **С соседями:** коротко про каждого соседа.
- **С миром:** список стран со статусом (союз, дружба, нейтрально, напряжённость, конфликт) и цветной меткой. На карте можно включить режим «Отношения»: выбранная страна в центре, остальные окрашены по статусу.
- **Отношение жителей к другим народам** — только по опросам (Pew Research Center, Gallup, World Values Survey, местные социологи), с годом.

**💭 Стереотипы**
- Вверху всегда есть пометка: *«Стереотип — это упрощённое мнение о большой группе людей. Он не описывает каждого человека и часто неверен».*
- Два блока:
  - «Что думают о жителях»;
  - «Что думают сами жители о других».
- Формат каждого пункта: **Стереотип → Как на самом деле**, со ссылкой на источник, если он есть.
- Правила:
  - и положительные, и отрицательные стереотипы — поровну;
  - без оскорбительных слов и прозвищ народов;
  - не сравнивать народы по принципу «лучше / хуже», не приписывать врождённые качества;
  - «как на самом деле» объясняет, откуда взялся стереотип (история, климат, традиции) и где он ошибается.

### 4.4. Исторические буклеты (машина времени)
Те же вкладки, где они имеют смысл: Обзор (годы, столица, вехи), Политика (как управлялось государство), Культура и народы, Отношения (с соседями своего времени). Плюс блок «Что сегодня на этой земле» со ссылками на современные страны.

## 5. Фото на весь экран

- Любое фото открывается в PhotoSwipe: обложка, галерея, карточки мест, чудеса света, находки эпохи, блюда.
- Все фото текущего раздела объединяются в одну галерею: листаешь от первого к последнему.
- Управление:
  - увеличение двумя пальцами, колёсиком или двойным нажатием;
  - листание свайпом или клавишами ← →;
  - закрытие жестом вниз, клавишей Esc или кнопкой ✕.
- Внизу подпись: название, страна, автор, лицензия, ссылка на страницу файла на Commons.
- **Размеры:** в буклете грузится версия 480 или 1200 px (через `srcset`), на весь экран — 2000 px. Пока загружается большая, показывается маленькая (без белого экрана).
- Фото на мелких карточках грузятся только тогда, когда до них доходит прокрутка (`loading="lazy"`).

## 6. Карта (MapLibre GL)

### 6.1. Основа
- Вид по умолчанию — плоская карта. Кнопка «🌐 Глобус» переключает на шар.
- Слои снизу вверх:
  1. Рельеф (растровые плитки, сделанные из Blue Marble: zoom 0–6).
  2. Страны: заливка по региону в режиме «Регионы» или прозрачная в режиме «Рельеф».
  3. Границы.
  4. Выбранная страна (обводка).
  5. Столицы.
  6. Булавки.
  7. Подписи.
- Границы: Natural Earth **50m** по умолчанию, **10m** — с zoom 5 и ближе (подгружаются по требованию).
- Небольшие страны и острова (Мальта, Сингапур, Мальдивы, Сокотра) видны и нажимаются: если страна меньше 8 px на экране, вокруг неё есть невидимый круг радиусом 12 px, по которому можно попасть.

### 6.2. Что видно на каком масштабе (уровни zoom)

| Zoom | Что видно |
|---|---|
| 0–1.5 | Чудеса света ★, значки крупных стран, названия средних стран |
| 1.5–3 | + значки всех стран, главные природные места, столицы крупных стран |
| 3–5 | + все природные места и заповедники, все столицы, подписи булавок |
| 5+ | + крупные города, все подписи |

- Приоритеты при наложении (чем меньше число, тем важнее): выбранная страна и её места — 0, чудеса света — 1, значки стран — 2, главные природные места — 3, заповедники — 4, остальная природа — 5, названия стран без значка — 6.
- **Правило «никто не пропадает навсегда»:** при zoom 6 и ближе любая булавка в кадре видна. Это проверяется тестом.
- Близкие булавки одного типа при zoom меньше 4 собираются в кружок с числом. Нажатие на кружок приближает карту.
- Значок страны стоит в «полюсе недоступности» (точке внутри страны, дальше всего от границ), а не в центре масс (иначе значок России оказывается в Казахстане). Для стран из нескольких частей — в самой большой части.

### 6.3. Фильтры и режимы
- Панель «Слои» (чекбоксы): страны, природа, заповедники, чудеса света, столицы, города. Выбор запоминается в localStorage.
- Режим «Отношения» (см. вкладку «Отношения»).
- Управление клавишами из раздела 1.2 сохраняется. Плюс F — найти, G — глобус.

## 7. Машина времени

### 7.1. Данные
- Исходник — **Cliopatria** (Seshat Global History Databank, CC BY 4.0).
- Скрипт `build-history.ts`:
  - разрезает данные на файлы по векам (`history/-0300.json` и т.д.), каждый до 3 МБ;
  - упрощает геометрию с сохранением островов: `mapshaper -simplify interval=…` и `keep-shapes`. Не используй `-filter-slivers` (он удаляет острова);
  - соседние века подгружаются заранее, пока смотришь текущий.
- Агрегаты — строки, у которых имя в скобках, например «(British Empire)» — не рисуются отдельно. Они используются для общей подписи и общего цвета колоний (поле `MemberOf`). Союзы и вассальные связи (`Alliance`, `Allegiance`, `Vassalage`, `Personal union`) — отдельный слой «Связи», выключенный по умолчанию.
- **Пустоты в древности:** добавь бледным цветом племена и культуры из historical-basemaps (GPL-3.0) отдельным слоем «Народы и культуры». Его можно выключить. Лицензию укажи в источниках.

### 7.2. Проигрыватель
- Год на большом табло, как в видео «история мира на карте».
- Пуск / пауза, скорость 0.5×–8×, полоса прокрутки лет, поле «перейти к году» (с выбором «до н.э. / н.э.»).
- **Плавная смена границ:** новое государство проявляется, исчезающее растворяется примерно за 300 мс.
- **Подсветка изменений:** когда граница сильно меняется (рост или потеря больше 20% площади, появление или исчезновение крупного государства), на карте мигает контур и всплывает подпись, например «1991 — распад СССР».
- Под полосой лет — метки ключевых событий из `epochs/events.json`. Нажатие на метку переносит в этот год.
- Режим **«История одной страны»**: выбираешь современную страну, и машина времени показывает только государства на её территории, с подписями по эпохам.

### 7.3. Буклеты
- Сейчас есть 77 подробных. Добавь ещё 60–80. В первую очередь:
  - Казахское ханство, Золотая Орда, Тимуриды, Сельджуки;
  - Великая Моравия, Кордовский халифат, Альмохады;
  - Империя Мали и Ашанти, Сонгай, Великий Зимбабве, Аксум;
  - Ацтеки, майя, инки;
  - Ахемениды, Сасаниды, Маурья, Гупта.
- Для остальных государств — автокарточка: годы на карте, «в составе», «сегодня здесь», события мира в эти годы.

## 8. Поиск
- Одно поле поиска сверху (клавиша F). Ищет по:
  - странам;
  - столицам и городам;
  - достопримечательностям, природе, заповедникам, чудесам света;
  - историческим государствам (с годами).
- Понимает русский и английский, прощает опечатки и неправильную раскладку (например, «rfpf[cnfy» → «казахстан»).
- Подсказки по группам с иконками. Управление стрелками и Enter.
- При выборе карта плавно перелетает к месту и открывает буклет на нужной вкладке. Историческое государство открывает машину времени на его годах.

## 9. Обучение и игра
- **Викторина** (5 или 10 вопросов, счёт в конце):
  - угадай страну по контуру;
  - какой стране принадлежала эта земля в N году;
  - чем знаменита страна;
  - найди на карте (нажми на страну).
- **«Исследователь»:** отмечаешь страны, где побывал или о которых прочитал. Счётчик «Изучено 34 из 177», значок на карте. Хранится в localStorage.
- **Случайная экскурсия:** 5 мест с коротким рассказом и автоматическим перелётом карты.

## 10. Оформление

### 10.1. Дизайн
- Стиль путеводителя: тёплая бумага, аккуратные карточки, крупные фото, цветные метки регионов.
- Шрифты: для заголовков — с характером (например, Unbounded или Playfair Display), для текста — читаемый (Inter или PT Sans). Оба с кириллицей.
- Цвета задаются CSS-переменными (**токенами**) в `styles/tokens.css`. Тёмная тема переопределяет те же переменные.
- Цвета регионов, природы (зелёный), заповедников (тёмно-зелёный), чудес света (золотой) сохраняются из старой версии.

### 10.2. Раскладка
- **Компьютер (больше 1000 px):** карта слева (около 62% ширины), буклет справа, прокручивается отдельно.
- **Планшет (700–1000 px):** карта сверху, буклет снизу.
- **Телефон (меньше 700 px):** карта на весь экран, буклет — выдвижная панель снизу (**bottom sheet**) с тремя положениями: свёрнута, половина экрана, весь экран.
- Отступы по бокам не меньше 16 px. Нет горизонтальной прокрутки при ширине 360 px.

### 10.3. Доступность
- Контраст текста по стандарту WCAG AA в обеих темах.
- Все кнопки и значки доступны с клавиатуры (Tab, Enter), фокус виден только при работе с клавиатуры (`:focus-visible`), без рамки при нажатии мышью или пальцем.
- Подписи для экранного диктора (**ARIA-метки**) у кнопок, вкладок, карты.
- Учитывай настройку «уменьшить движение» (`prefers-reduced-motion`): отключай анимации перелётов и вспышки.

## 13. Порядок работы (этапы)

Каждый этап заканчивается **рабочей версией** и отчётом со скриншотами.

1. **Разбор.** Прочитай старый HTML, перечисли найденные данные и функции. Сверь с разделом 1, сообщи о расхождениях.
2. **Извлечение.** Скрипт `extract-legacy.ts` переносит все данные в `content/` и `public/`. Проверка: числа совпадают (177 стран, 158+57 природных мест, 21 чудо, 77 исторических буклетов, ≈1550 государств, все фото).
3. **Каркас.** Vite + React + TS, раскладка, темы, роутер, хранилище.
4. **Карта.** MapLibre, слои, значки, булавки, подписи по уровням, кластеры, фильтры, клавиши.
5. **Буклет.** Шапка и 6 вкладок на перенесённых данных. Пустые разделы — «Скоро появится».
6. **Фото.** Скрипты `fetch-commons.ts` и `build-images.ts`, PhotoSwipe, галереи. Сетку найденных фото показываешь мне на проверку.
7. **Машина времени.** Перенос, плавность, подсветка изменений, метки событий, режим «История одной страны», слой «Народы и культуры».
8. **Наполнение текстами.** Сначала 50 самых популярных стран (практическая информация, климат, кухня, культура, отношения, стереотипы), потом остальные.
9. **Поиск, викторина, «Исследователь», сравнение стран.**
10. **Полировка:** доступность, скорость, печать, сборка без интернета, страница источников.
